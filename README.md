# .github
FEYMAN Technology organization profile

The public organization profile uses English by default. The language links at the top of each profile let visitors open the English or Simplified Chinese version.

| Language | Profile source |
| --- | --- |
| English (default) | [profile/README.md](profile/README.md) |
| 简体中文 | [profile/README.zh-CN.md](profile/README.zh-CN.md) |

Keep both versions in sync when updating the organization profile. To add another language, create a translated file in `profile/` and add its language link to every version.
