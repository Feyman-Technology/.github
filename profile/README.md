## About FEYMAN

FEYMAN develops positioning and sensing modules for surveying, precision agriculture, construction, machine control, and robotics.

## Explore our technology

| Series | Focus |
| --- | --- |
| **IM** | IMU & attitude sensing |
| **PM** | GNSS positioning |
| **VM** | Vision |
| **RM** | Time-of-flight ranging |
| **MC** | Machine control & AHRS |

[Explore products on our website](https://www.feymani.com/)

## Start building

- **Explore repositories** — Visit our [public repository list](https://github.com/orgs/Feyman-Technology/repositories). For each published project, start with its README for setup, examples, and compatibility information.
- **Find resources** — Visit the [official website](https://www.feymani.com/) for product resources.
- **Discuss an integration** — Contact [fmi-support@feymani.com](mailto:fmi-support@feymani.com) for product and integration inquiries.

## Collaborate

For a published repository with Issues enabled, report reproducible problems or suggest improvements there. Please include the product model, relevant software versions, steps to reproduce, and expected behavior.

Before submitting a pull request, check that repository's contribution instructions and license. Source availability and reuse permissions are defined per repository.
