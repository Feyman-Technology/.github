## About FEYMAN · 关于我们

FEYMAN develops positioning and sensing modules for surveying, precision agriculture, construction, machine control, and robotics.

FEYMAN 面向测绘、精准农业、工程施工、机器控制和机器人应用，研发定位与感知模块。

## Collaborate · 交流与贡献

For a published repository with Issues enabled, report reproducible problems or suggest improvements there. Please include the product model, relevant software versions, steps to reproduce, and expected behavior.

对于已发布且开启 Issues 的仓库，欢迎提交可复现的问题或改进建议。请附上产品型号、相关软件版本、复现步骤和预期行为。

Before submitting a pull request, check that repository's contribution instructions and license. Source availability and reuse permissions are defined per repository.

提交 Pull Request 前，请查看对应仓库的贡献说明和许可证。代码开放范围及使用权限以各仓库声明为准。
